# MarketManager


## Lancer en local

**Prérequis:** Node.js 18+

1. Installer les dépendances:
   `npm install`
2. Démarrer le serveur de développement:
   `npm run dev`
3. Ouvrir l'application sur `http://localhost:3000`

## Production

1. Générer le bundle:
   `npm run build`
2. Démarrer le serveur en mode production:
   `NODE_ENV=production npm run preview`
